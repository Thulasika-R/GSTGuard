
# GSTGuard

Machine Learning-Based Anomaly Detection for Automated GST Invoice Fraud Detection to Support MSME Compliance.

## Project Overview

GSTGuard is a web application project designed to help MSMEs review GST invoice data, identify unusual invoice patterns, and compare new invoices with shop-specific historical records.

## Planned Features

- Invoice uploads: PDF, JPG, JPEG and PNG
- CSV invoice import and validation
- Machine learning-based anomaly detection
- Shop-specific invoice history
- Risk analysis dashboard and reports
- Settings and application preferences

## Technology Stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Machine Learning: Pandas, NumPy, scikit-learn
- Database: To be decided

## Development Status

Initial development and environment setup.

## Disclaimer

An anomaly score identifies unusual patterns and does not, by itself, prove fraud or establish GST non-compliance.
